# El alma errante

Primera versión estática y responsive de la página web transmedia. No necesita instalación ni servidor.

## Abrir la página

Abre `index.html` en cualquier navegador moderno (doble clic o la opción “Abrir con”). Para una experiencia más cercana a producción, puede servirse la carpeta con cualquier servidor local estático.

## Contenido y cuidado

- Incluye Inicio, Historias y testimonios, Un espacio para recordar, Acompañamiento y Comparte tu historia.
- Los dos relatos están señalados inequívocamente como ficticios.
- El formulario es únicamente visual: el botón no envía ni guarda texto; el sitio además advierte no incluir datos personales o sensibles.
- Las imágenes se cargan desde Unsplash cuando hay conexión. La interfaz conserva sus fondos y estructura si no se cargan.
